# Omega Valley Team Studio assets

The GitHub Pages team room uses Three.js and four complete rigged Quaternius character bodies.

- **Three.js 0.186.1**: MIT licensed. The license text is in `three/LICENSE`.
- **Character GLBs**: `worker_male`, `worker_female`, `cowboy_male`, and `oldclassy_female`. Source: [Quaternius Animated Characters Pack on OpenGameArt](https://opengameart.org/content/animated-characters-pack). License: CC0, as recorded in the project character manifest. The office reuses these four full bodies to represent the project team; team names and roles are project-created labels.
- **Character source pack page**: [OpenGameArt Animated Characters Pack](https://opengameart.org/content/animated-characters-pack).

These files are used by the standalone `team.html` scene. They are not part of the village game build.
